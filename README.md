# Song Decoder — Live Caption Terminal

This repository contains a live caption-to-terminal bridge for videos and caption tracks you own or are authorized to process.

## Run

Open VS Code in the live-caption-bridge folder and run:

    py caption_terminal.py

Then follow the setup guide in live-caption-bridge/README.md to load the Chrome/Edge extension and connect it to the terminal.

The extension forwards new cues from active, visible native HTML5 caption tracks and animates each line in multiple colours. It does not record audio, transcribe songs, read hidden transcripts, or fetch lyrics. YouTube, YouTube Music and Spotify are intentionally unsupported.
